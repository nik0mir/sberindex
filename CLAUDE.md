# СберИндекс 2026 — направление «Кластеризация»

Решение для конкурса СберИндекса по анализу данных. Подача до **9 октября 2026 включительно**, цель — 8 октября.
План по этапам и критериям жюри — `PLAN.md`. Положение: https://sber.ru/common/assets/sber/sberindex_polozhenie_o_konkurse.pdf

## Главное из Положения

- Участник или команда выбирает **только одно направление** (п. 3.1). Наше — «Кластеризация».
- Сдаём: репозиторий GitHub (чистый код, гиперпараметры в YAML/JSON, инструкция запуска), краткий методологический
  отчёт на русском, презентацию PDF или интерактивный лендинг с экономической интерпретацией (п. 1.8).
- Критерии (п. 6.1): методология 15%, сетевая и атрибутивная структура 15%, сравнение методов 15%,
  ICVI (SW, CH, S_Dbw, AVI, AVU, MQ) 15%, **интерпретация и воспроизводимость 30%**, визуализация 10%.
  Шкала «плохо/удовл./хорошо/отлично» — Приложение 1, выписана в `PLAN.md`.
- Проект делается с нуля во время конкурса (п. 9.1.2); платные проприетарные технологии в решении запрещены (п. 10.3).
- В заявке нужен e-mail на российском домене; заявку отправляет каждый участник команды (п. 3.2).

## Данные

- СберИндекс: безналичные расходы на уровне МО (2023-01…2024-12, 6 категорий), индекс доступности рынков,
  автодорожные связи, справочник границ МО (ОКТМО, полигоны, преобразования). Лицензия CC BY-SA 4.0 — источник указываем.
  Описание: https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim
- Росстат, БД ПМО через «Если быть точным» (https://tochno.st/datasets/bdmo, CC BY 4.0): среднемесячная зарплата и
  среднесписочная численность по разделам ОКВЭД2 (без малого бизнеса). Структура занятости = доли разделов.
  Плюс население, розница, общепит, отгрузка, инвестиции, КСР, число организаций и ИП; доходы — 5-НДФЛ ФНС
  (https://tochno.st/datasets/ndfl). Сопоставление с СберИндексом — через ОКТМО из справочника границ.
- Всё скачивает `make data` в `data/raw/<источник>/` со сверкой sha256; состав, покрытие и ловушки
  (формат ОКТМО, нарастающие итоги, «без МСП») — `docs/materials.md`.
- Нужные домены в Network access окружения (Custom + домены по умолчанию): `sber.ru`, `s.sber.ru`, `sberindex.ru`,
  `www.sberbank.com`, `www.sberbank.ru`, `storage.yandexcloud.net`, `tochno.st`, `rosstat.gov.ru`,
  `pypi.org`, `files.pythonhosted.org`. В облаке PyPI открыт только через прокси агента:
  `NO_PROXY=localhost,127.0.0.1 no_proxy=localhost,127.0.0.1 uv sync --frozen`.
- Сайтам Сбера нужны сертификаты из `certs/` (временная папка, загрузчик берёт их через `download.ca_files`).

## Договорённости

- Общение, отчёт и лендинг — на русском; типографика по скилу `ru-text`.
- Скилы — в `.claude/skills/`, источники и правки — в `THIRD_PARTY.md`. Из сторонних скилов убираем любые требования
  ссылаться на их авторов или раскрывать использование инструментов; лицензии оставляем (юридически обязательны).
- Работы других участников открыты (github.com/IvanFrolovskiy/sberindex-atlas, github.com/Vestovka/sberindex-clustering):
  смотреть можно, копировать код нельзя. Выделяемся ясностью и интерпретацией, а не числом методов.
- Репозиторий приватный до подачи.

## Агенты (.claude/agents, инструкция — docs/agents.md)

- Делают: expert-data (панель, соединения, разведка: этапы panel, eda, features), expert-economist (сюжет,
  смысл типов), expert-network (рёбра), expert-clustering (методы, динамика), expert-icvi (ICVI),
  expert-viz (графики для жюри, лендинг), expert-writer (тексты).
- Проверяют, файлы не правят: check-facts (данные и числа), check-repro (прогон с нуля), check-ux (понятность),
  devils-advocate (опровергнуть вывод). Оценивают по шкале: judge-c1…c6 по критерию, judge-council — сводный балл.
- После эксперта — проверщик; в конце этапа — судья его критерия; 04.10 и 06–07.10 — judge-council.
- Факты о данных и полная шкала жюри — скил munnet-agents (разделы 5 и 6).
