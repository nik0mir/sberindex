# Лендинг «Корзина и регион»

Интерактивная страница с итогами проекта: карта 1776 муниципалитетов с типом и 169 без типа, поиск своего
муниципалитета, карточка с типом, корзиной трат относительно своего региона и списками для сверки, паспорта
типов, проверки выводов, динамика, таблица всех муниципалитетов и источники с лицензиями.

**Адрес:** https://nik0mir.github.io/sberindex/ — заработает после публикации 08.10.2026 (репозиторий до подачи
закрыт, GitHub Pages включается после его открытия).

## Как открыть локально

Из корня репозитория:

```bash
uv run --frozen python -m http.server 8000 -d site
```

и откройте http://localhost:8000/. Подойдёт любой статический сервер; страница не обращается к внешним адресам:
шрифты, three.js и данные лежат в этой папке.

**Если открыть `index.html` двойным щелчком** (адрес `file://…`), видна плоская карта ячеек без объёма.
Браузеры на основе Chromium (Chrome, Edge, Яндекс Браузер) не загружают модули JavaScript с `file://`,
а объёмная карта — модуль three.js из `vendor/`. Данные вписаны прямо в `index.html`, поэтому поиск, карточки,
главы и таблица работают и так.

## Откуда страница

- Собирает этап `site`: `uv run --frozen python -m munnet site` (модуль `src/munnet/landing.py`, шаблоны
  `src/munnet/templates/`). Этапу нужны выходы всех предыдущих этапов; полный прогон с нуля —
  `uv run --frozen python -m munnet all` (около 3 ч, см. README репозитория).
- Коммит кода, из которого собрана страница, и отпечаток результатов (`facts.json`, sha256) указаны в подвале
  страницы. Коммит, в котором лежит эта сборка, — `git log -1 -- site/`.
- Этап пишет сюда `index.html`, `data/` (JSON и выгрузки CSV в `data/download/`) и `vendor/` (three.js 0.170.0,
  MIT; шрифты Golos Text и Unbounded, OFL); этот файл он не трогает.
- Публикация — ветка `gh-pages`: в ней лежит содержимое этой папки (`git subtree split --prefix site`), а GitHub
  Pages показывает её корень (Settings → Pages → Deploy from a branch → `gh-pages`, `/ (root)`). Пустой файл
  `.nojekyll` отключает обработку страницы генератором Jekyll.
