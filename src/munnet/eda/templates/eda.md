## Какой сюжет выбрать

Матрица — подсказка, выбор делает участник. Итог = Σ вес × балл (1–5). Веса выведены из критериев жюри: сила
сигнала {{syn.weight_signal}}, сеть и динамика {{syn.weight_network_dynamics}}, практическая ценность
{{syn.weight_practical}}, покрытие {{syn.weight_coverage}}, объяснимость {{syn.weight_explainability}}, риски
данных {{syn.weight_data_risk}}. Баллы силы сигнала и покрытия посчитаны из фактов разведки, остальные —
экспертные (`src/munnet/eda/stories.py`, участник вправе их изменить). Сюжет может стать главным, только если
выполнены все его критерии отказа; иначе он «слой» (выполнен хотя бы один критерий силы сигнала) или «контекст»,
независимо от балла.

## Ограничения и ловушки данных

- **Номинал.** Суммы в текущих рублях: рост 2024 года к 2023-му включает инфляцию. Реальный рост не считается,
  пока в `eda.cpi` нет официального помесячного ИПЦ Росстата.
<!-- if e1 -->
- **Покрытие.** Выводы — о {{e1.n_regions}} регионах с данными, а не обо всей России: целиком выпали
  {{e1.absent_regions}}; вне них нет ещё {{e1.n_missing_outside}} МО справочника. ЗАТО в панели нет.
<!-- endif -->
- **Чьи траты.** Траты привязаны к жителям МО: траты приезжих в курортном МО не видны, траты жителей вне своего
  МО (поездки, онлайн) по смыслу входят, но как модель СберИндекса их привязывает, не раскрыто. Наличные не
  видны.
- **Место работы.** 5-НДФЛ и занятость Росстата считаются по месту работодателя; у внутригородских территорий
  Москвы и Петербурга показатели «на жителя» по месту работы не считаются.
- **Без МСП.** Зарплата и занятость Росстата — без малого бизнеса: они описывают крупные и средние организации.
- **Объединения 2024 года.** У МО-предшественников ряд заканчивается в 2023 году, у преемников начинается
  в 2024-м; ряды не склеиваются.

## Как пересобрать и проверить

Из корня репозитория (Windows: Git Bash или PowerShell; нужен [uv](https://docs.astral.sh/uv/)):

```bash
uv run --frozen python -m munnet panel eda        # панель и разведка (данные — после этапа data)
uv run --frozen python -m munnet eda --only e3    # один раздел: пишет только свои файлы
uv run --frozen python -m munnet eda --only syn   # сводка, общие выходы и этот отчёт из итогов разделов
```

С `make`: `make panel eda`, один раздел — `make eda ONLY=e3`.

Каждое число текста — в `outputs/eda/facts.json` (значение, вид, готовый текст, определение); реестр
рисунков — `outputs/eda/figures.json`, таблиц — `outputs/eda/tables.json`; данные каждого рисунка — CSV
в `outputs/eda/data/`. Если вывод в заголовке рисунка перестал быть верным, сборка останавливается с кодом 3,
а этот файл не перезаписывается.

## Словарь

- **МО** — муниципальное образование: район, округ, городской округ или внутригородская территория Москвы
  и Петербурга.
- **ОКТМО** — код МО в классификаторе территорий; нужен только как мост к Росстату и ФНС.
- **Типичное МО** — медиана по МО без весов; **типичный житель** — среднее по МО с весами населения.
- **Номинал** — суммы в рублях своего года, без поправки на инфляцию.
- **п. п.** — процентные пункты: разность двух долей в процентах.
- **CLR** — центрированный логарифм отношения: логарифм доли категории к среднему геометрическому всех долей
  корзины. Сравнивает доли, не нарушая их сумму.
- **MAD** — медианное абсолютное отклонение; MAD × 1,4826 — устойчивая к выбросам оценка разброса.
- **η² региона** — доля разброса показателя между регионами в общем разбросе: близко к единице — показатель
  почти целиком задаётся регионом.
- **I Морана** — насколько значения МО похожи на значения ближайших соседей; перестановочный тест сравнивает его
  с тем же числом на перемешанных МО.
- **Перестановочный нуль** — то же число на данных, где связь разрушена перемешиванием: показывает, сколько
  «сигнала» даёт случайность.
- **Свой ритм** — годовой профиль МО после снятия его линейного тренда и общего ритма календарного месяца.
