# configs/ca — сертификаты удостоверяющих центров для загрузчика

Без них этап `data` не открывает часть сайтов с данными конкурса. Загрузчик (`src/munnet/data.py`) добавляет
эти файлы к системным корневым сертификатам через `download.ca_files` в `configs/default.yaml`. Проверка TLS
нигде не отключается.

| Файл | Для каких сайтов | Зачем |
|---|---|---|
| `russian_trusted_ca.pem` | www.sberbank.ru, www.sberbank.com, rosstat.gov.ru | сертификат от УЦ Минцифры, его нет в стандартных хранилищах |
| `litessl_rsa_ca_2025.pem` | sberindex.ru | сервер не отдаёт промежуточный сертификат, корня TrustAsia нет в хранилищах; загрузчик включает `VERIFY_X509_PARTIAL_CHAIN` |

Отпечатки SHA-256 и поля subject/issuer записаны в начале каждого `.pem`. Это публичные сертификаты УЦ, не ключи.

До 02.10.2026 файлы лежали во временной папке `certs/` вместе со вспомогательным скриптом проверки доступа;
папка удалена, код от неё не зависит.
