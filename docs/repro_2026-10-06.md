## Отчёты этапов в git

После прогона `git status` в копии показал изменёнными шесть файлов. В них различаются только концы строк, замеры
времени и коммит сборки с отпечатком:

- `docs/eda.md`, `docs/icvi.md`, `docs/interpretation.md` — только концы строк: код пишет LF, а Git в Windows
  с `core.autocrlf=true` записывает файлы с концами строк CRLF; без учёта `\r` текст совпадает с коммитом.
- `docs/clustering.md` — только время: «около 43 мин» против «около 69 мин», бутстрап 3 против 4 мин, пересчёт
  на других входах 8 против 13 мин; в двух таблицах у гауссовой смеси класс времени «< 1 с» против «1–10 с».
- `site/index.html` и `site/data/story.json` — коммит сборки и отпечаток результатов, как в таблице выше.

## Чего этот прогон не проверял

- Linux и macOS: прогон шёл в Windows 10 через Git Bash.
- Другой компьютер: прогон шёл на том же компьютере, где велась разработка.
- Скачивание данных из источников и распаковку архивов: sha256 сверены на уже скачанных файлах.
- Команды `make`: `make setup` и `make all` не запускались, потому что `make` на этом компьютере нет; вместо них
  те же шаги выполнены напрямую через `uv sync --frozen` и `uv run`.
