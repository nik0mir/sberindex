## Задача «Кластеризация»

Источник: https://sber.ru/sberindex/konkurs_sberindex

Построить **динамическую атрибутированную экономическую сеть**:

- узел — муниципальное образование (МО);
- у каждого МО свои экономические характеристики (атрибуты);
- рёбра отражают степень экономической близости МО;
- сеть строится для последовательности моментов времени (например, ежемесячно).

Три задачи: сгруппировать экономически схожие МО, проследить, как группы меняются во времени,
интерпретировать и наглядно показать результат. Кластеры нужно трактовать как реальные типы локальных экономик.

Для этого организаторы требуют:

1. Сформировать пространство признаков из предложенных показателей и обосновать выбор.
2. Математически определить правило, по которому между двумя МО возникает ребро.
3. Обосновать способ построения рёбер и объяснить, как он влияет на структуру сети и кластеры.
4. Предложить математический подход к отслеживанию изменений кластеров во времени.
5. Оценить качество кластеров, дать им содержательную интерпретацию и обосновать экономический смысл.

Обязательно использовать хотя бы один датасет СберИндекса. Можно добавлять новости, климат и погоду,
другие экономические индикаторы и любые надёжные публичные источники.

Варианты рёбер, которые организаторы перечисляют в критерии «Сетевая и атрибутивная структура» (15%):
корреляция рядов или косинусное сходство векторов расходов; лаговые корреляции и DTW, когда один
регион опережает другой; расстояния между регионами; другие варианты.

## Архив с данными конкурса

- https://www.sberbank.com/common/img/uploaded/files/pdf/sberindex/hackathonlicence.zip
- зеркало: https://sberindex.ru/api/files/download/7a675947-398d-45e6-8d61-c4299a6203be
- 19 603 203 байта, sha256 `a9f932ff4096a7df797d1547987937f34d3995ac445b4748177114488d12b010`
- лицензия CC BY-SA 4.0, формат цитирования — в PDF внутри архива.

Схема и объёмы прочитаны из метаданных parquet (pyarrow в облачном окружении пока нет, см. ниже).

| Файл | Строк | Поля | Содержание |
|---|---|---|---|
| `consumption.parquet` | 303 126 | `date` (строка `ГГГГ-ММ`), `territory_id` (int16), `category`, `value` (int32), служебный `__index_level_0__` | Средние безналичные расходы жителя МО за месяц, руб. 2023-01…2024-12. Категории: «Все категории», «Продовольствие», «Здоровье», «Общественное питание», «Транспорт», «Маркетплейсы». Значения 10…91 003 |
| `market_access.parquet` | 2 571 | `territory_id` (int32), `market_access` (float64) | Индекс доступности рынков 2024 г.: MA_o = Σ_{d≠o} N_d / τ_od (N — население, τ — расстояние), нормирован к шкале до 1000. Фактический диапазон 110,3…1000. Нет 22 МО без постоянной дороги или парома |
| `connection.parquet` | 5 942 364 | `territory_id_x`, `territory_id_y` (int64), `distance` (float64, км), `type` (`highway` / `railway`) | Расстояния между центрами МО на 31.12.2024. Каждая пара записана один раз (x → y), обратное расстояние считается таким же. По железной дороге не связаны 1447 МО |

Нюансы:

- В PDF колонка расходов названа `consumption`, в файле — `value`.
- `territory_id` — МО в постоянных границах; тот же ключ, что в справочнике границ (ниже).
- Расходы есть примерно для 2100 МО (порог качества оценки), доступность рынков — для 2571,
  связи — для id до 3014. Значит, узлы сети — МО из `consumption`.
- Панель неполная: по выгрузке с дашборда около 165 названий МО имеют меньше 24 месяцев, из них 53 —
  ровно 12 месяцев. Для каждого МО-месяца есть все 6 категорий.

Формат у всех одинаковый: `;`, UTF-8 с BOM, поля `period`, `value`, `obs_status`, `source`, …, `unit_measure`.

| Изменение потребительских расходов (`ver-izmenenie-trat-po-kategoriyam`) | Россия | 2023-11…2026-09, неделя | 46 категорий, % г/г |
| Потребительская активность по возрастам | Россия | 2021-01…2026-09, неделя | 5 возрастных групп, индекс |

Выгрузка по МО — те же 303 126 строк, что в `consumption.parquet`, но с названием вместо `territory_id`
и без региона. 48 названий объединяют одноимённые МО разных регионов (6570 повторяющихся ключей
«МО × месяц × категория»). Поэтому работаем с parquet, а CSV годится только для сверки.
Остальные четыре выгрузки — по России целиком: это макрофон (общие шоки), а не атрибуты узлов.

## Справочник границ и изменений МО

Страница: https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities (CC BY-SA 4.0).
Архив RAR: https://s.sber.ru/GthXk7 (обновление 25.10.2024).
Метаданные: https://www.sberbank.ru/common/img/uploaded/files/pdf/sberindex/metadata_municipal_dict_sberindex_2.pdf

- Покрытие 01.01.2018…01.01.2024, только МО верхнего уровня; новых регионов нет.
- `t_dict_municipal_districts` — версии МО: `territory_id`, `region_code`, `oktmo`, названия, тип, статус,
  центр и его координаты (для городов федерального значения координат нет — брать центроид полигона),
  `shape` (1 — центр внутри, 2 — центр в соседнем МО, 3 — центр одновременно для соседнего),
  `change_id_from` / `change_id_to` (union, disunion, transfer), `year_from` (включительно) / `year_to` (не включая).
- `t_dict_municipal_districts_poly` — полигоны OSM по `territory_id` и годам.
- Срез на год: `df[(df.year_from <= Y) & (df.year_to > Y)]`, затем соединение с полигонами по `territory_id`.

Справочник — единственный мост `territory_id` ↔ ОКТМО, без него не присоединить данные Росстата и не
нарисовать карту.

## Другие наборы sberindex.ru

В каталоге https://sberindex.ru/ru/dashboards/ 21 набор, на уровне МО — только два:

- расходы на уровне МО (см. выше);
- индекс мобильности по Северо-Западному ФО: 297 МО, среднемесячные значения за январь–сентябрь 2024
  и 2025 гг. (две точки), медианный «радиус инерции» покупок жителя. Годится как атрибут только для СЗФО.

Остальное — Россия или регионы: потребительская активность, прогноз и декомпозиция инфляции,
медианная зарплата, активные торговые точки, обороты бизнеса, недвижимость, ФОТ по ОКВЭД,
внутренний туризм, реальная ключевая ставка.
