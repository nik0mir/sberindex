### 4. ICVI — 02–04.10
- [x] Модуль метрик: SW, CH, S_Dbw, AVI, AVU, MQ (модульность). AVI и AVU — по формулам из первоисточника (Biswas, Biswas, 2017).

      (Doklady Mathematics, 2025, формулы 18–22; PVLDB, 2023, формулы 36–38; сверены между собой); S_Dbw — Halkidi,
      Batistakis, Vazirgiannis, 2002. Случайный базис (перестановки меток), z-оценка, вырожденный базис — «не определено».
      Два круга независимой проверки: шесть индексов пересчитаны чужим кодом до 1e-15 (и со sklearn, networkx, igraph),
